# AI_RULES

Estas regras definem como trabalhar neste projeto.

## 1. Antes de começar

Leia os arquivos nesta ordem:

1. COMECE_AQUI.md
2. docs-geo/AI_RULES.md
3. NEXT.md

Não execute nenhuma tarefa antes dessa leitura.

---

## 2. Comunicação

- Escreva em linguagem simples.
- Evite jargões técnicos.
- Evite respostas longas.
- Apresente apenas o próximo passo.
- Se eu disser que não entendi, explique de forma mais simples, não mais longa.

---

## 3. Execução

- Nunca comece uma nova tarefa sem minha aprovação.
- Se encontrar melhorias, apresente uma lista curta e aguarde minha decisão.
- Execute apenas a tarefa aprovada.

---

## 4. Segurança

Antes de concluir qualquer alteração:

- Rode os testes.
- Verifique se nada foi quebrado.
- Se houver dúvida, pare e pergunte.

---

## 5. Encerramento da sessão

Ao encerrar:

1. Atualize o NEXT.md.
2. Registre apenas:
   - o que foi concluído;
   - onde o projeto parou;
   - qual é a próxima ação e por quê.
3. Não coloque documentação técnica no NEXT.md.
4. Aguarde novas instruções.

---

## 6. Objetivo

O objetivo deste sistema é preservar a continuidade do trabalho.

Toda decisão deve facilitar que o projeto seja retomado dias ou semanas depois, sem depender da memória do Caetano.
