# TRADUZIR

Todo o texto em português do iaieu.com, visível e invisível, para tradução em inglês e espanhol.

## Como usar este arquivo

Cada item tem três linhas:

```
IDENTIFICADOR | tipo do texto
arquivo, linha
texto em português
```

O identificador é fixo. Ele nunca muda, nunca se repete e nunca é reaproveitado, mesmo que o texto seja reescrito depois.

Quando o mesmo texto aparece mais de uma vez na página, ele entra uma vez só e a linha de referência lista todas as ocorrências. Uma tradução serve para todas.

`NAO_TRADUZIR` marca o item que precisa ficar idêntico nos três idiomas: nome da marca, nomes de pessoas e empresas, telefone, e-mail e endereços de internet. `contém NAO_TRADUZIR` marca o texto que deve ser traduzido, mas preservando dentro dele os nomes próprios que aparecem.

O texto está exatamente como está no site, sem correção e sem ajuste.

## Regras de escrita que valem nas três línguas

- Sem travessão, em nenhum contexto.
- O nome da marca é IAieu, sempre com essa grafia. Nunca "Instituto".
- "Eu" para o que o Caetano executa. "IAieu" para método, filosofia e marca. Plural apenas quando incluir o cliente de verdade.
- Nunca prometer transformar uma operação antes de conhecê-la.
- Depoimento de terceiro não se reescreve. Traduzir o que a pessoa disse, sem melhorar.
